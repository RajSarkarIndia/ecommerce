E-Commerce Microservices Application

Built with Spring Boot, Angular, PostgreSQL, Stripe and Google Cloud Storage

Architecture Overview

This project follows a microservices architecture.

  • Angular Frontend
  • Spring Cloud Gateway
  • Eureka Service Discovery
  • Authentication Service (JWT Security)
  • Product Service (Google Cloud Storage Integration)
  • Order Service
  • Payment Service (Stripe Integration)
  • PostgreSQL Databases

Microservices

Eureka Server

Service registry where all microservices register themselves.

Gateway Service

Single entry point for all client requests. Handles routing and JWT validation.

Authentication Service
  • User Registration
  • User Login
  • JWT Token Generation
  • User Profile Management
  • Address Management
Product Service
  • Create, Update and Delete Products
  • Fetch All Products
  • Category Filtering
  • Image Upload to Google Cloud Storage
  • Generate Signed Download URLs
Order Service
  • Create Orders
  • Store Order Items
  • Track Delivery Status
  • Track Payment Status
Payment Service
  • Stripe Payment Integration
  • Create Payment Session
  • Webhook Handling
  • Payment Status Tracking

Security Flow

  1. User logs in using Authentication Service.
  2. JWT token is generated.
  3. Frontend stores the token.
  4. Token is sent in Authorization header.
  5. Gateway validates JWT before forwarding request.

Database

Each microservice uses PostgreSQL.

spring.datasource.username=YOUR_DB_USERNAME
spring.datasource.password=YOUR_DB_PASSWORD

Environment Configuration (.env)

export ProjectId=YOUR_PROJECT_ID
export BucketName=YOUR_BUCKET_NAME
export dbUsername=postgres
export dbPassword=YOUR_DB_PASSWORD

export stripeKey=YOUR_STRIPE_SECRET_KEY
export webhookSecret=YOUR_WEBHOOK_SECRET
Variable Usage
Variable Used By Purpose
ProjectId Product Service Google Cloud Project ID
BucketName Product Service Google Cloud Storage Bucket
dbUsername All Services Database Username
dbPassword All Services Database Password
stripeKey Payment Service Stripe Secret Key
webhookSecret Payment Service Stripe Webhook Verification Secret
